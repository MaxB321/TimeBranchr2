# TimeBranchr2
This is a new version of my old TimeBranchr App. 

**This is a work in progress!!!**

## Description
App designed for tracking time for specific activities. 

There is a triple heirarchy structure. This means you can have an outer activity followed by a mid layer activity, and finally and inner layer activity.
See Below for example:
- Studying: 100 hrs
    - Math: 50 hrs
        - Linear Algebra: 25 hrs
        - Trigonometry: 25 hrs
    - Science: 50 hrs
        - Biology: 25 hrs
        - Anatomy: 25 hrs


## What is different from Version 1?
**This is fully Client Based!**
This means there is no server, and also no database! This version of the app is strictly home to the local device. 
Persistence is achieved through simple local file reading/writing.
